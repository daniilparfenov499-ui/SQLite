📊 ПРИМЕРЫ SQL ЗАПРОСОВ:

Получить всех активных спортсменов:
  SELECT * FROM athletes WHERE status = 'активный';

Вывести расписание тренировок на неделю:
  SELECT * FROM v_weekly_training_schedule WHERE session_date >= DATE('now');

Получить результаты соревнований:
  SELECT * FROM v_competition_results ORDER BY match_date DESC;

Рассчитать общие доходы:
  SELECT SUM(amount) as total_revenue FROM payments WHERE status = 'успешно';

Найти активные подписки:
  SELECT * FROM v_active_subscriptions;
